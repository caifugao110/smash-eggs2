# 砸金蛋 · 认汉字 🥚🔨

面向 **3–6 岁**小朋友的汉字启蒙网页小游戏。砸开金蛋、找出字宝宝，在互动中认识常用汉字。

纯前端、零依赖、单文件即可运行，支持**鼠标与触屏**，内置**真人语音**与丰富的**自定义设置**。

![license](https://img.shields.io/badge/license-MIT-green) ![deps](https://img.shields.io/badge/dependencies-0-blue)

## ✨ 特色

- **140 个常用汉字 · 17 个主题世界 · 68 个关卡**
  数字、动物、自然、身体、家人、方向大小、颜色、生活、水果、蔬菜、食物、交通、服饰、学习用品、天气季节、美好品德，外加随机复习的「智慧闯关岛」。
- **真人语音朗读**：预生成的神经网络童声（晓晓），读音自然不生硬；无网络时自动回退到浏览器语音。
- **丰富互动反馈**：金蛋摇晃、裂纹、砸开弹字、彩纸粒子、星星评价、贴纸收集册。
- **完整自定义设置**：金蛋数量、每关字数、提示等待、语速、自动朗读、显示拼音/组词、真人语音/背景音乐/音效独立开关、重置进度。
- **触屏友好**：点按即砸、敲击锤子特效、禁用长按菜单与双击缩放、大按钮热区。
- **进度自动保存**：星星、已学汉字、设置均存于浏览器本地。
- **音乐盒背景旋律 + 合成音效**：全部由 Web Audio 实时生成，无需音频素材。

## 🚀 运行

无需安装、无需构建，直接用浏览器打开 `index.html` 即可。

推荐用本地静态服务器打开（部分浏览器对 `file://` 的音频/字体有限制）：

```bash
# 任选其一
python -m http.server 8080
# 或
npx --yes serve -l 8080 .
```

然后访问 <http://localhost:8080>。

## 🎮 玩法

1. 首页点「开始冒险」进入当前关卡。
2. 看顶部字卡（ emoji + 拼音 + 汉字 + 组词），听语音读题。
3. 点一点金蛋把它砸开，砸出与字卡相同的汉字即过关。
4. 每关认识若干字，按错得星评价（0 错 = 3 星），通关解锁下一关与新世界。
5. 在「贴纸册」复习已学汉字，点贴纸可再听读音。

## ⚙️ 设置项

| 设置 | 说明 |
| --- | --- |
| 金蛋数量 | 每回合 3 / 4 / 5 个蛋（难度） |
| 每关字数 | 一关 3 / 4 / 5 个字 |
| 提示等待 | 关闭 / 5 / 9 / 15 秒后闪烁提示正确蛋 |
| 语音语速 | 慢速 / 正常 |
| 自动朗读题目 | 进入回合自动读字 |
| 显示拼音 / 显示组词 | 字卡与贴纸册的辅助信息开关 |
| 真人语音 / 背景音乐 / 游戏音效 | 三路声音独立开关 |
| 重置学习进度 | 清空星星与贴纸（保留设置） |

右上角 🔊 为声音总开关，一键静音全部声音。

## 🗂️ 目录结构

```
smash-eggs2/
├─ index.html        # 游戏本体（HTML + CSS + JS 单文件）
├─ v/                # 预生成真人语音片段 + manifest.js
├─ gen_phrases.mjs   # 从 index.html 提取朗读文案
├─ gen_voice.py      # 用 edge-tts 批量生成语音
├─ LICENSE           # MIT
└─ README.md
```

## 🔊 重新生成语音（可选）

语音片段已随仓库提供，开箱即用。若新增汉字或想换音色，可重新生成：

```bash
pip install edge-tts
node gen_phrases.mjs     # 生成 phrases.json
python gen_voice.py      # 生成 v/*.mp3 与 v/manifest.js
```

默认音色 `zh-CN-XiaoxiaoNeural`，语速 `-8%`，可在 `gen_voice.py` 中修改。
